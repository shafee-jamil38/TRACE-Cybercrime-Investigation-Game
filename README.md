# 🎮 TRACE – A Cybercrime Investigation Game

TRACE is a text-based cybercrime investigation game developed in Java using Object-Oriented Programming (OOP) concepts.

The player takes the role of a cybercrime investigator and investigates a simulated security breach by analyzing logs, tracing suspicious connections, discovering hidden servers, recovering deleted evidence, and identifying the real attacker.

---

## 🎮 Game Overview

### Case 01: The Silent Breach

A secure government database has been compromised.

A suspicious login is detected at **02:14 AM** using the credentials of `employee_17`.

You are the cybercrime investigator assigned to the case.

### Your Mission

- Investigate suspicious login activity
- Trace suspicious IP addresses
- Analyze network traffic
- Discover hidden servers
- Investigate privileged sessions
- Recover deleted evidence
- Identify the real attacker

## 🧠 Investigation Chapters

### Chapter 1 – The Log-In Mystery

Investigate a suspicious login associated with `employee_17`.

You can:

- Trace the suspicious IP
- Analyze network traffic
- Investigate the hidden server
- Continue tracing the connection

### Chapter 2 – The Hidden Server

The investigation leads to an unknown server.

You investigate:

- Server logs
- Server location
- Server security
- Privileged sessions

### Chapter 3 – The Insider

Evidence suggests that `employee_17` may not be the real attacker.

You investigate:

- Administrator accounts
- Privileged sessions
- Access records
- Insider activity

### Chapter 4 – The Final Trace

The final stage of the investigation focuses on recovering deleted evidence and identifying the insider behind the attack.

## 🎯 Game Mechanics

The player must make investigation decisions throughout the case.

Correct investigation choices can:

- Discover new clues
- Increase the investigation score
- Progress to the next chapter
- Reveal additional evidence

The player also has a limited number of investigation attempts.

---

## 📊 Scoring & Ranking System

The player's performance is evaluated using an investigation score.

### Investigator Ranks

| Score | Rank |
|------:|------|
| 165+ | 🏆 Elite Investigator |
| 145+ | ⭐ Senior Investigator |
| 125+ | 🔎 Field Investigator |
| Below 125 | 🟢 Rookie Investigator |
