# TRACE – A Cybercrime Investigation Game

TRACE is a text-based cybercrime investigation game developed in Java.

The player takes the role of a cybercrime investigator and investigates a simulated security breach by analyzing logs, tracing suspicious connections, discovering hidden servers, and identifying the real attacker.

## 🎮 Game Overview

### Case 01: The Silent Breach

A secure government database has been compromised.

A suspicious login is detected at 02:14 AM using the credentials of `employee_17`.

Your mission is to:

- Investigate suspicious login activity
- Trace suspicious IP addresses
- Analyze network traffic
- Discover hidden servers
- Investigate privileged sessions
- Recover deleted evidence
- Identify the real attacker

## ✨ Features

- 🔍 Cybercrime investigation gameplay
- 🧩 Evidence and clue-based investigation
